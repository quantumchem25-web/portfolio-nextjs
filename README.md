# Portfolio — Next.js

A world-class portfolio website built with:

- **Next.js 14** (App Router)
- **Framer Motion** — entrance reveals, hover effects, magnetic buttons
- **GSAP ScrollTrigger** — parallax hero, animated counters
- **Tailwind CSS** — dark premium theme

## Sections

Hero · Marquee · About · Services · Work · Experience · Testimonials · Contact

## Run locally

```bash
npm install
npm run dev
```

## Customize

All content lives in `lib/data.js` — name, bio, projects, skills, socials.
